<objective>
Make local build artifacts verifiable by adding explicit source distribution includes, artifact inspection tests, and local build metadata checks.
</objective>

<threat_model>
<assets>
- Source distribution and wheel artifacts that will eventually be uploaded to PyPI.
</assets>
<threats>
- MEDIUM: missing `LICENSE`, README, or package files in a release artifact creates an unusable or non-compliant distribution.
- LOW: generated `dist/` artifacts accidentally get committed.
</threats>
<mitigations>
- Add artifact inspection tests for sdist/wheel contents.
- Ensure build output directories are ignored by git.
</mitigations>
</threat_model>

<tasks>
<task id="33-02-T1" type="execute">
<read_first>
- `pyproject.toml`
- `.gitignore`
- `.planning/phases/33-package-metadata-and-build-readiness/33-RESEARCH.md`
</read_first>
<action>
Add explicit Hatch source distribution include rules:

```toml
[tool.hatch.build.targets.sdist]
include = [
    "/corpulse",
    "/README.md",
    "/LICENSE",
    "/pyproject.toml",
]
```

Keep the existing wheel package rule:

```toml
[tool.hatch.build.targets.wheel]
packages = ["corpulse"]
```

Update `.gitignore` so it contains these generated build artifacts if missing:

```gitignore
dist/
build/
*.egg-info/
```
</action>
<acceptance_criteria>
- `pyproject.toml` contains `[tool.hatch.build.targets.sdist]`.
- `pyproject.toml` contains `"/README.md"`.
- `pyproject.toml` contains `"/LICENSE"`.
- `pyproject.toml` still contains `packages = ["corpulse"]`.
- `.gitignore` contains `dist/`.
- `.gitignore` contains `build/`.
- `.gitignore` contains `*.egg-info/`.
</acceptance_criteria>
</task>

<action>
Add artifact-oriented tests in `tests/test_package.py` that:

- Assert `[tool.hatch.build.targets.sdist]` exists.
- Assert the sdist include list contains `/corpulse`, `/README.md`, `/LICENSE`, and `/pyproject.toml`.
- If `dist/*.tar.gz` exists, open the newest tarball with Python `tarfile` and assert it contains entries ending in `pyproject.toml`, `README.md`, `LICENSE`, and `corpulse/__init__.py`.
- If `dist/*.whl` exists, open the newest wheel with Python `zipfile` and assert it contains `corpulse/__init__.py` and a `.dist-info/METADATA` file.
- Skip artifact-file inspection when no `dist/` artifact exists so normal unit tests do not require a prior build.
</action>
<acceptance_criteria>
- `tests/test_package.py` contains `test_sdist_include_configuration`.
- `tests/test_package.py` imports `tarfile`.
- `tests/test_package.py` imports `zipfile`.
- `tests/test_package.py` contains `pytest.skip("No built artifacts found")`.
- `python -m pytest tests/test_package.py` exits 0 before and after local artifact build.
</acceptance_criteria>
</task>
