<objective>
Make `pyproject.toml` credible for PyPI and remove version drift by configuring Hatchling to read the package version from `corpulse/__init__.py`.
</objective>

<threat_model>
<assets>
- Published package metadata shown to PyPI users.
- Runtime `corpulse.__version__` used by adopters and diagnostics.
</assets>
<threats>
- LOW: misleading or incomplete project metadata reduces user trust.
- LOW: version drift causes published artifact metadata to disagree with runtime imports.
</threats>
<mitigations>
- Add explicit tests for metadata fields and dynamic Hatch version configuration.
- Preserve runtime `__version__` and verify metadata no longer contains a duplicate static version.
</mitigations>
</threat_model>
