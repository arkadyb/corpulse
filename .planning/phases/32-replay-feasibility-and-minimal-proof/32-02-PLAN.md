# Plan 32-02 - Shared Replay Helper and Sync Facade

## Goal

<objective>
Implement the dependency-free callable replay proof and expose it through the sync `Corpulse` facade.
</objective>

## Must Haves

- Uses only Python standard library plus existing corpulse model imports.
- Does not add backend methods or storage schema.
- Does not add OpenAI, HTTP, or benchmark dependencies.
- Sorts traces by `(captured_at, trace_id)`.
- Does not sleep by default.
- Does not store handler return values in the report.

  <action>
    Create `corpulse/replay.py` with standard-library imports only.

    Define:
    - `ReplayHandler = Callable[[ReplayRequest], Any]`
    - `_ordered_replay_traces(traces: Iterable[RagRequestTraceRow]) -> list[RagRequestTraceRow]`
    - `_scaled_delay(previous: RagRequestTraceRow | None, current: RagRequestTraceRow, *, time_scale: float | None, max_delay_seconds: float | None) -> float`
    - `_build_replay_request(trace: RagRequestTraceRow, *, sequence_index: int, scheduled_delay_seconds: float) -> ReplayRequest`
    - `replay_rag_request_traces(traces: Iterable[RagRequestTraceRow], handler: ReplayHandler, *, time_scale: float | None = None, max_delay_seconds: float | None = None, stop_on_error: bool = False, sleep: Callable[[float], None] | None = time.sleep, clock: Callable[[], float] = time.monotonic) -> ReplayReportPayload`

    Required behavior:
    - `_ordered_replay_traces` returns traces sorted by `(captured_at, trace_id)`.
    - `_scaled_delay` returns `0.0` when `time_scale is None`.
    - `_scaled_delay` raises `ValueError("time_scale must be greater than 0")` when `time_scale <= 0`.
    - `_scaled_delay` computes `max(current["captured_at"] - previous["captured_at"], 0.0) / time_scale` when previous exists.
    - `_scaled_delay` caps the delay with `max_delay_seconds` when that argument is not `None`.
    - `replay_rag_request_traces` calls `sleep(delay)` only when `delay > 0` and `sleep is not None`.
    - The handler receives a `ReplayRequest` built from trace fields and `scheduled_delay_seconds`.
    - Handler return values are ignored and are not stored in the report.
    - Handler exceptions are caught and recorded as `ReplayResult` rows with `ok: False` and `error: str(exc)`.
    - If `stop_on_error=True`, no remaining traces are invoked after the first handler exception and `skipped_count` equals the number of remaining traces.
    - `summary["trace_count"]` is the number of input traces.
    - `summary["replayed_count"]` is the number of handler invocations.
  </action>
