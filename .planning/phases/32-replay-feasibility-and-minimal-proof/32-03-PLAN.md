# Plan 32-03 - Async Replay Facade and Docstring Coverage

## Goal

<objective>
Add async replay parity while keeping replay semantics shared with the sync helper.
</objective>

## Must Haves

- Async replay awaits a user-provided async callable.
- Async replay uses the same ordering, delay, error, and summary semantics as sync replay.
- No aggregation or replay envelope logic is duplicated in `async_core.py`.
- Public async method includes an `Args:` docstring section.
