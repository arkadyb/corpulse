# Plan 32-04 - Replay Documentation and Regression Verification

## Goal

<objective>
Document callable replay, record the replay decision in project planning artifacts, and run the regression suite that proves Phase 32 integrates with imported workload traces.
</objective>

## Must Haves

- README explains `replay_rag_request_traces(...)` and `areplay_rag_request_traces(...)`.
- README states that replay uses captured or JSONL-imported traces.
- README states that core corpulse does not include a built-in OpenAI SDK or HTTP replay client.
- PROJECT and REQUIREMENTS reflect Phase 32 completion boundaries after execution.
- Regression tests include replay, JSONL, trace capture, backend contract, and docstrings.
