<objective>
Expose file and stream based JSONL export/import on the sync `Corpulse` facade with append-oriented, duplicate-safe import behavior.
</objective>

<truths>
- D-05: Import appends to the selected backend and does not clear existing data.
- D-06/D-07: Re-importing the same export skips duplicates under normal usage.
- D-08: Replacement or destructive restore semantics are out of scope.
- D-12/D-13/D-14: The documented primary API is on `Corpulse`, accepts paths and text streams where practical, and uses shared helpers.
- D-17: Import returns structured counts.
</truths>

<threat_model>
T-29-01 Raw data exposure: sync export must keep `include_raw_text=False` and `include_component_metadata=False` defaults.

T-29-02 Malformed import corruption: sync import must pass `strict=True` by default to the shared parser and fail clearly on invalid JSONL.

T-29-03 Duplicate import inflation: sync import must compute existing destination fingerprints before inserting and increment `skipped_duplicates` instead of inserting duplicates.
</threat_model>

<action>
In `corpulse/core.py`, add public method `Corpulse.import_rag_request_traces_jsonl(...) -> RagRequestTraceImportResult` near `export_rag_request_traces_jsonl` with this signature:

```python
def import_rag_request_traces_jsonl(
    self,
    source,
    *,
    strict: bool = True,
) -> RagRequestTraceImportResult:
```

Behavior:
- accept a `str`, `pathlib.Path`, or text IO object as `source`
- read non-empty lines using `encoding="utf-8"` for path sources
- parse each line with `parse_rag_request_trace_jsonl_line(line, line_number=line_number, strict=strict)`
- build `existing_rag_request_trace_fingerprints(self.get_rag_request_traces(window_days=None))` before insert
- for duplicate fingerprints, increment `skipped_duplicates` and do not insert
- for valid new records, call `self.db.insert_rag_request_trace(...)` with the parsed `request_id`, `session_id`, `query_text`, `query_hash`, `input_token_count`, `output_token_count`, `components`, `timings`, `timeout`, `error`, and `captured_at`
- return `{"total": total, "imported": imported, "skipped_duplicates": skipped_duplicates, "invalid": invalid, "errors": errors}`
- with `strict=True`, raise `ValueError` on the first invalid record after including the line number in the message
- with `strict=False`, collect invalid line messages in `errors`, increment `invalid`, continue processing, and return counts
</action>

- `rg "RagRequestTraceImportResult|parse_rag_request_trace_jsonl_line|existing_rag_request_trace_fingerprints|insert_rag_request_trace" corpulse/core.py` exits 0.
- `rg "skipped_duplicates|invalid|errors|strict: bool = True" corpulse/core.py` exits 0.
</acceptance_criteria>
</task>
