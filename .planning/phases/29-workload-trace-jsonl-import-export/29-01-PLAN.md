<objective>
Add the shared JSONL serialization, validation, privacy redaction, import result, and duplicate fingerprinting primitives that sync and async public APIs will use.
</objective>

<truths>
- D-01: JSONL is line-only; no wrapper object, header line, or sidecar metadata file.
- D-02: Every exported record contains `schema_version: "corpulse.rag_request_trace.v1"`.
- D-03: Export preserves analytics and replay-ready `RagRequestTraceRow` fields.
- D-09/D-10/D-11: Privacy-first export omits raw query text and component metadata unless explicitly opted in.
- D-15/D-16/D-17: Import is strict by default and permissive mode must report invalid/skipped lines.
</truths>

<threat_model>
T-29-01 Raw data exposure: a default export could include raw user queries or caller-controlled component metadata. Mitigation: default serializer output must set or omit `query_text` as `None` and strip component `metadata` unless explicit include flags are set.

T-29-02 Malformed import corruption: malformed JSONL could create unusable analytics rows. Mitigation: strict parser rejects invalid JSON, unsupported schema versions, non-object records, non-list components, non-object timings, non-boolean timeout, and missing `captured_at`.

T-29-03 Duplicate import inflation: re-importing the same export could inflate future workload reports. Mitigation: add deterministic fingerprint helpers over analytics-relevant fields excluding local `trace_id`.
</threat_model>

<task id="29-01-T2" type="execute">
<title>Create workload JSONL codec module</title>
<read_first>

<action>
Create `corpulse/workload_io.py` using only Python standard-library imports plus corpulse model imports.

The module must define:
- `RAG_REQUEST_TRACE_JSONL_SCHEMA = "corpulse.rag_request_trace.v1"`
- `serialize_rag_request_trace_jsonl(trace: RagRequestTraceRow, *, include_raw_text: bool = False, include_component_metadata: bool = False) -> str`
- `parse_rag_request_trace_jsonl_line(line: str, *, line_number: int, strict: bool = True) -> RagRequestTraceRow`
- `rag_request_trace_fingerprint(trace: RagRequestTraceRow) -> str`
- `existing_rag_request_trace_fingerprints(traces: list[RagRequestTraceRow]) -> set[str]`

`serialize_rag_request_trace_jsonl` must:
- return one compact JSON object string without a trailing newline
- include `schema_version`
- include `trace_id`, `request_id`, `session_id`, `query_hash`, `input_token_count`, `output_token_count`, `components`, `timings`, `timeout`, `error`, and `captured_at`
- include `query_text` only when `include_raw_text=True`
- include component `metadata` only when `include_component_metadata=True`
- use deterministic key ordering with `sort_keys=True`

`parse_rag_request_trace_jsonl_line` must:
- accept a single non-empty line
- reject invalid JSON and non-object JSON with `ValueError`
- reject any `schema_version` other than `corpulse.rag_request_trace.v1` with `ValueError`
- build a `RagRequestTraceRow`
- default missing optional fields to `None`, `[]`, or `{}` as appropriate
- reject missing or invalid `components`, `timings`, `timeout`, or `captured_at` in strict mode
- in permissive mode, still reject invalid JSON and unsupported schema version, but allow missing optional fields

`rag_request_trace_fingerprint` must produce a deterministic SHA-256 hex digest from a canonical JSON object containing:
- `request_id`
- `session_id`
- `query_hash`
- `input_token_count`
- `output_token_count`
- `components`
- `timings`
- `timeout`
- `error`
- `captured_at`

It must not include `trace_id`, `schema_version`, `query_text`, or component `metadata`.
</action>
