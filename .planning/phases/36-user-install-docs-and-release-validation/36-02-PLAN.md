</objective>

<threat_model>
<assets>
- Published `corpulse` package on PyPI.
- Published `corpulse[qdrant]` extra dependency resolution.
- Clean environment smoke checks.
</assets>
<threats>
- HIGH T36-04: Maintainer publishes a package that cannot be installed from PyPI in a clean environment.

- MEDIUM T36-06: Local wheel validation passes, but published-package validation is skipped or not recorded.
</threats>
<mitigations>
- Document exact base and Qdrant smoke commands in `.github/RELEASE_CHECKLIST.md`.
- Keep published-package validation manual and explicit because it depends on external PyPI state.
- Run local build and opt-in wheel install tests before external publish smoke checks.
</mitigations>
</threat_model>
