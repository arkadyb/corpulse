## Goal

Add typed serving report payloads and pure aggregation helpers that summarize latency distributions, stage latencies, timeout/error rates, and slow-request contributors from trace timing data.

## Must Haves

- Report is descriptive and inference-free.
- Missing timing fields are ignored per metric instead of failing the report.
- Timeout/error rates are computed across all traces in the window.
- Slow contributors are based only on measured stage timings.
- Empty trace windows return stable zero-count payloads.
