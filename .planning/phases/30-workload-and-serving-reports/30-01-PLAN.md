## Goal

Add typed workload report payloads and pure aggregation helpers that summarize request traffic, token pressure, and component composition from `RagRequestTraceRow` values.

## Must Haves

- Report is derived only from trace fields.
- Empty trace windows return a stable zero-count payload.
- Component aggregation covers all canonical component types and groups unknown/missing values as `other`.
- Long-context pressure uses a configurable input-token threshold with a default of 8000.
- Percentiles use deterministic nearest-rank semantics.
