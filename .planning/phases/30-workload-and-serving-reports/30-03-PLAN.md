## Goal

Expose workload and serving reports through the sync and async public clients while keeping all aggregation logic shared.

## Must Haves

- Sync and async methods return the same payload shapes.
- Public methods fetch traces through the existing trace APIs.
- Aggregation remains in shared helper functions.
- Public methods include Args docstrings.
- No existing public method behavior changes.
