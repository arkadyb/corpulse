Create `rag_memento/integrations/qdrant.py` with these exact components:

1. **Module-level:** `from __future__ import annotations` and `import asyncio`. NO qdrant_client imports at module level (Pitfall 4). Define `__all__ = ["QdrantMementoClient", "AsyncQdrantMementoClient"]`.

2. **`_normalize_points(points, call_kwargs, payload_id_field, payload_filename_key)` function:**
   - Pure function, no side effects
   - For each ScoredPoint `p` in `points`:
     - `payload = p.payload or {}`
     - If `payload_id_field is None`: `doc_id = str(p.id)`. Else: `doc_id = payload.get(payload_id_field, str(p.id))`
     - `filename = payload.get(payload_filename_key, doc_id)`
     - `embedding = p.vector if call_kwargs.get("with_vectors", False) else None`
     - If `isinstance(embedding, dict)`: `embedding = next(iter(embedding.values()), None)` (named vectors case)
     - Append `{"doc_id": doc_id, "filename": filename, "score": p.score, "embedding": embedding}`
   - Return the list of dicts
   - Return empty list if `points` is empty

3. **`QdrantMementoClient` class:**
   - `__init__(self, client, memento, *, payload_id_field=None, payload_filename_key="filename")`:
     - FIRST line: `self._client = client` (Pitfall 5: prevents __getattr__ recursion)
     - SECOND: `self._memento = memento`
     - THIRD: `self._payload_id_field = payload_id_field`
     - FOURTH: `self._payload_filename_key = payload_filename_key`
     - FIFTH: Lazy import guard: `try: from qdrant_client import QdrantClient except ImportError: raise ImportError("Install qdrant-client: pip install rag-memento[qdrant]")`
   - `query_points(self, collection_name, **kwargs)`:
     - `result = self._client.query_points(collection_name=collection_name, **kwargs)`
     - Access `result.points` (NOT iterate result directly -- Pitfall 2)
     - If `result.points`: call `_normalize_points(result.points, kwargs, self._payload_id_field, self._payload_filename_key)` then `self._memento.log_retrieval(records, query="")`
     - `return result` unchanged (QDRT-04)
   - `search(self, collection_name, **kwargs)`:
     - `result = self._client.search(collection_name=collection_name, **kwargs)` (delegates; raises AttributeError if client lacks search -- Pitfall 1)
     - search() returned `list[ScoredPoint]` directly (not QueryResponse)
     - If `result`: call `_normalize_points(result, kwargs, self._payload_id_field, self._payload_filename_key)` then `self._memento.log_retrieval(records, query="")`
     - `return result`
   - `__getattr__(self, name)`: `return getattr(self._client, name)`

4. **`AsyncQdrantMementoClient` class:**
   - Same `__init__` as sync version but import guard checks `from qdrant_client import AsyncQdrantClient`
   - `async def query_points(self, collection_name, **kwargs)`:
     - `result = await self._client.query_points(collection_name=collection_name, **kwargs)`
     - If `result.points`: normalize then `await asyncio.to_thread(self._memento.log_retrieval, records, "")`
     - `return result`
   - `async def search(self, collection_name, **kwargs)`:
     - `result = await self._client.search(collection_name=collection_name, **kwargs)`
     - If `result`: normalize then `await asyncio.to_thread(self._memento.log_retrieval, records, "")`
     - `return result`
   - `__getattr__(self, name)`: `return getattr(self._client, name)`

IMPORTANT: Do NOT catch Qdrant exceptions in intercepted methods. Let them propagate (Anti-pattern from research).
