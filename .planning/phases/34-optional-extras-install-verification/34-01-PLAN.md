<objective>
Add an isolated install verification harness that installs the built wheel into a clean virtual environment and proves the base package imports without optional integration dependencies.
</objective>

<threat_model>
<assets>
- Local wheel artifacts under `dist/`.
- The base `corpulse` install contract.
- Optional dependency boundaries for integrations.
</assets>
<threats>
- MEDIUM T34-01: Optional integrations accidentally become base dependencies, making the core install heavier and less reliable.
- LOW T34-02: Install checks pass locally because the developer environment already has optional packages installed.
</threats>
<mitigations>
- Run install checks inside a newly created venv.
- Assert optional modules are absent after base wheel install.
- Gate slow/network-dependent install tests behind `CORPULSE_RUN_INSTALL_TESTS=1` so normal unit tests stay fast.
</mitigations>
</threat_model>

<action>
Create `tests/test_distribution_installs.py` with pytest tests and helper functions for clean virtual environment install checks.

The file must:
- import `os`, `pathlib`, `subprocess`, `sys`, `textwrap`, `venv`, and `pytest`.
- define `RUN_INSTALL_TESTS = os.environ.get("CORPULSE_RUN_INSTALL_TESTS") == "1"`.
- define `pytestmark = pytest.mark.skipif(not RUN_INSTALL_TESTS, reason="set CORPULSE_RUN_INSTALL_TESTS=1 to run isolated install tests")`.
- define `_repo_root()` returning `pathlib.Path(__file__).resolve().parent.parent`.
- define `_latest_wheel()` that finds `dist/*.whl`, skips with `pytest.skip("No built wheel found; run python -m build first")` when none exist, and returns the newest wheel by `stat().st_mtime`.
- define `_create_venv(tmp_path)` that creates a venv under `tmp_path / "venv"` with pip enabled.
- define `_python(venv_dir)` that returns `venv_dir / "Scripts" / "python.exe"` on Windows and `venv_dir / "bin" / "python"` otherwise.
- define `_run(py, args)` that runs subprocess commands with `check=True`, `text=True`, and captured stdout/stderr.
- define `_install_wheel(py, wheel, extra=None)` that installs either the wheel path directly or a PEP 508 direct URL requirement formatted as `corpulse[{extra}] @ {wheel.resolve().as_uri()}`.
</action>
