# Plan 31-01 - Session Report Models and Summary Aggregation

## Goal

Add typed session report payloads and pure helper logic for request count, turns per session, session duration, follow-up rate, and history growth.

## Must Haves

- Uses only `RagRequestTraceRow` values.
- Does not add backend methods or storage schema.
- Counts missing and blank `session_id` values as unsessioned.
- Orders session traces by `(captured_at, trace_id)`.
- Empty input returns a stable zero-count payload.

  <action>
    Add `_build_session_report(traces)` in `corpulse/core.py`. For this task, populate `summary` and `sessions`; return an empty `context_reuse` list until Plan 31-02 extends it.

    Required behavior:
    - Convert input traces to a list.
    - Treat `session_id is None` or `session_id.strip() == ""` as unsessioned.
    - Group only non-empty session IDs.
    - Sort each session's traces by `(captured_at, trace_id)`.
    - `duration_seconds = last_captured_at - first_captured_at`, rounded to 2 decimals.
    - `input_token_growth = input_tokens_last - input_tokens_first` when both endpoints exist, otherwise `None`.
    - `chat_history_*` values come from summed `chat_history` component token counts per request; growth is `last - first` when both endpoints exist, otherwise `None`.
    - `follow_up_rate = multi_turn_session_count / session_count`, rounded to 2 decimals, or `0.0` when no sessions exist.
  </action>
