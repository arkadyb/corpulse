# Plan 31-03 - Public Sync and Async Session Report API

## Goal

Expose `session_report(...)` through sync and async clients while keeping aggregation in the shared helper.

## Must Haves

- Sync and async methods return the same payload shape.
- Both methods fetch traces through existing `get_rag_request_traces(...)`.
- No aggregation logic is duplicated in `async_core.py`.
- Public methods include Args docstrings.
- Existing workload and serving reports remain unchanged.
