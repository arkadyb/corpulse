From the official Psycopg pool docs:
- Connection pools live in the separate `psycopg_pool` package.
- Sync usage pattern is `with pool.connection() as conn: ...`.
- If constructor-open semantics are required, specify `open=True` explicitly and call `wait()` when startup readiness matters.
