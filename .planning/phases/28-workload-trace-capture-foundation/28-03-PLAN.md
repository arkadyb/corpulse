<objective>
Expose the workload trace capture surface through `Corpulse` and `AsyncCorpulse`, with sync/async parity and tests.
</objective>

<truths>
- This plan depends on backend storage methods from plans 28-01 and 28-02.
- Public APIs must be additive and must not alter retrieval or generation trace semantics.
- `query_hash` should be derived with `_hash_query(query)` when query text is present.
</truths>

<threat_model>
The public API can accidentally encourage raw prompt retention. Keep `query` optional, allow `query_hash`-only operation, and do not require component content bodies.
</threat_model>

<tasks>
<task id="28-03-T1" type="execute">
<title>Add sync workload trace facade</title>
<read_first>
- corpulse/core.py
- corpulse/models.py
- tests/test_trace_capture.py
</read_first>
<action>
In `corpulse/core.py`:
- import `RagRequestComponent`, `RagRequestTimings`, and `RagRequestTraceRow`
- add `Corpulse.log_rag_request(...) -> None`
- add `Corpulse.get_rag_request_traces(window_days: int | None = None) -> list[RagRequestTraceRow]`

`log_rag_request` parameters must include:
- `session_id: str | None = None`
- `query: str | None = None`
- `request_id: str | None = None`
- `components: list[RagRequestComponent] | None = None`
- `input_token_count: int | None = None`
- `output_token_count: int | None = None`
- `timings: RagRequestTimings | None = None`
- `timeout: bool = False`
- `error: str | None = None`

When `query` is not `None`, pass `_hash_query(query)` as `query_hash`; otherwise pass `None`.
Default `components` to `[]` and `timings` to `{}`.
</action>
