# Requirements Archive: corpulse v1.6

**Archived:** 2026-04-20
**Milestone:** v1.6 — Generation Trace Capture
**Outcome:** shipped

## Shipped Requirements

### v1.6 Generation Trace Capture Foundation

- [x] **v1.6-01**: `Corpulse` and `AsyncCorpulse` expose an additive trace-capture API that records prompt/query text, retrieved context references, final answer text, and optional evaluation labels without changing existing retrieval or engagement methods.
- [x] **v1.6-02**: The trace-capture surface persists and retrieves records through the backend contract with sync/async parity and deterministic ordering, while remaining append-only and optional.
- [x] **v1.6-03**: Existing retrieval analytics, corpus-health reporting, and current storage contracts remain unchanged; no generation scoring is implemented in this milestone.
