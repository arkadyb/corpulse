### v1.1 Pluggable Storage Backends

- [x] **ABS-01**: `StorageBackend` ABC defines the shared backend contract
- [x] **ABS-02**: Shared typed row contracts exist across backends
- [x] **ABS-03**: `StorageBackendError` wraps native backend exceptions
- [x] **ABS-04**: Shared parametrized backend tests cover shipped backend implementations
- [x] **BACK-01**: `SQLiteBackend` preserves existing behavior under the new abstraction
- [x] **BACK-02**: `corpulse.db` remains a compatibility alias
- [x] **BACK-03**: `InMemoryBackend` provides fileless test-friendly storage
- [x] **BACK-04**: `PostgresBackend` ships with schema auto-init and pooled sync operation support
- [x] **BACK-05**: `AsyncPostgresBackend` ships with async initialization and pooled operation support
- [x] **BACK-06**: All shipped backends support lifecycle management
- [x] **INT-01**: `Corpulse(backend=...)` supports explicit backend injection with SQLite default
- [x] **INT-02**: Optional extras ship as `[postgres]` for `psycopg[pool]` and `[postgres-async]` for `asyncpg`
- [x] **INT-03**: Sync and async Postgres backends support connection pooling on recorded proof

- `BACK-04` was initially satisfied in Phase 7, then hardened and re-verified in Phase 9 when pooled sync support became milestone-critical.
