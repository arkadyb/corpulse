<objective>
Ensure every optional integration failure gives an actionable install command while preserving fallback behavior for optional reporting helpers.
</objective>

<threat_model>
<assets>
- Error messages users see when optional dependencies are absent.
- Optional integration setup experience.
- Base install lightness.
</assets>
<threats>
- LOW T34-06: Users hit optional integration errors without a copyable install command.
- LOW T34-07: Reporting helpers that should gracefully degrade start raising unnecessary optional dependency errors.
</threats>
<mitigations>
- Standardize missing-extra messages to include `pip install corpulse[...]`.
- Preserve pandas direct install guidance because it is not a declared package extra.
- Preserve tabulate fallback behavior and test that no error is raised when tabulate is absent.
</mitigations>
</threat_model>
