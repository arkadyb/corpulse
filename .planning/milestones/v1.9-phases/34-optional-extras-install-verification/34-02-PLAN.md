<objective>
Extend the isolated install harness so the Qdrant, Postgres, async Postgres, and FastAPI extras install cleanly from the built wheel, with Qdrant wrapper imports verified from the extra install.
</objective>

<threat_model>
<assets>
- Optional extra dependency declarations in `pyproject.toml`.
- Public integration import surfaces.
- Built wheel metadata.
</assets>
<threats>
- MEDIUM T34-03: Optional extras are declared but fail to resolve from the built artifact.
- MEDIUM T34-04: Qdrant extra installs but does not expose the expected wrapper classes.
- LOW T34-05: Existing optional extras have undocumented install constraints.
</threats>
<mitigations>
- Install each extra from a local wheel using a PEP 508 direct URL requirement.
- Assert dependency imports after each extra install.
- Assert Qdrant wrapper classes import through the package root after installing `corpulse[qdrant]`.
</mitigations>
</threat_model>
